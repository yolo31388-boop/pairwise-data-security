# 游戏内数据加密与防篡改系统

## 项目描述

游戏内数据加密与防篡改系统的bug修复项目。核心模块 `security/data_security.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 数据加密只用简单XOR很容易破解
- 数据解密没有验证完整性可能损坏
- 校验和只用简单求和很容易伪造
- 密钥硬编码在代码里所有人都一样
- 防篡改检测完全没做改存档不告警

## 运行测试

```bash
python -m pytest tests/test_data_security.py -q
```

修复目标：所有 14 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
